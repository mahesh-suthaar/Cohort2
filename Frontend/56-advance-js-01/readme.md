# Classes in javascript

### 01. Syntax
```javascript
class demo {
        //properties

        //methods/functions
    }
```

### 02. `Constructor(){}` method:
#### A constructor is a special method/function that automatically runs when an object/instance is created from a class. <br>Constructor can receive data through perameters. <br>for example: `Constructor(name, age){}`

### 03. `new` keyword:
#### The new keyword is used to create an object/instance from a class.
#### for example:
```javascript
let car1 = new Car();
```
